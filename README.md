# Punto Nieve Bakery

Landing page para agendar pedidos de repostería artesanal.

- Sitio: https://punto-nieve-bakery.vercel.app
- Repositorio conectado a Vercel: cada cambio en `main` se publica solo.
- Todo el sitio está en `index.html` (HTML, CSS y JS, sin dependencias).

## Configurar WhatsApp

Al final de `index.html`, escribe el número del negocio en `WHATSAPP_NUMBER` (solo dígitos con código de país, p. ej. `50499998888`). Así, al agendar, el cliente verá un botón para enviar el pedido por WhatsApp.

## Pendiente de completar

Reemplaza los textos entre corchetes: `[PRECIO]`, `[DIRECCIÓN]`, `[CIUDAD]`, `[DÍAS]`, `[HORAS]`, `[NÚMERO]`, `[@USUARIO]`, `[X]%` y los recuadros `[Foto]`.

## Publicación

Cada cambio en la rama `main` se publica automáticamente en Vercel.
